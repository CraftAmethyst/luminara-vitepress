# stable/FeudalKings Installation

This page applies only to Minecraft `1.21.1`. Please first determine whether your modpack uses NeoForge or Fabric.

## 1. Download Luminara

Download the binary files matching `stable/FeudalKings`, Minecraft `1.21.1`, and your target platform from [GitHub Releases](https://github.com/CraftAmethyst/Luminara/releases). If the Release provides a checksum file, verify with:

::: code-group

```bash [Linux / macOS]
sha256sum luminara-*.jar
```

```powershell [Windows]
Get-FileHash .\luminara-*.jar -Algorithm SHA256
```

:::

## 2. NeoForge

1. Visit the [NeoForge Official Site](https://neoforged.net/), select Minecraft `1.21.1`, and download the `21.1.x` Installer (minimum `21.1.117`).
2. Run in a clean server directory:

   ```bash
   java -jar neoforge-21.1.x-installer.jar --installServer
   ```

3. Create `eula.txt` and write `eula=true`.
4. Place the NeoForge-compatible Luminara mod and your mods into `mods/`, and plugins into `plugins/`. Start the server using the startup script generated by NeoForge.

## 3. Fabric

1. Prepare a Fabric Dedicated Server for Minecraft `1.21.1`, using Fabric Loader `0.16.0` or higher.
2. Place Fabric API `0.115.0` or higher, the Fabric-compatible Luminara mod, and other mods into `mods/`.
3. Create `eula.txt`, write `eula=true`, and place plugins into `plugins/`.
4. Start the server using the Fabric server startup script.

Dependencies for Fabric and NeoForge are not interchangeable. After first startup, ensure `luminara.yml` is generated in the root directory, run `/luminara info`, and check the platform and `v1_21_R1` in the logs.
