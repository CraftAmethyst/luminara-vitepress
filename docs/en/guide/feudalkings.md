# `stable/FeudalKings` Installation

`stable/FeudalKings` is the Luminara branch targeting Minecraft `1.21.1`. It is completely independent of the Minecraft `1.20.1` / Forge environment in `stable/Trials`. Please select launchers and mod files according to the matrix below.

## Support Matrix

| Component | Requirement |
| --- | --- |
| Minecraft | `1.21.1` |
| Java | `21` or `25`, 64-bit JVM |
| NeoForge | `21.1.117` or higher `21.1.x` version |
| Fabric Loader | `0.16.0` or higher version |
| Fabric API | `0.115.0` or higher version (required for Fabric server) |
| CraftBukkit Package | `v1_21_R1` |

## Getting Files

Download build artifacts labeled `stable/FeudalKings`, `1.21.1`, or corresponding branch from [GitHub Releases](https://github.com/CraftAmethyst/Luminara/releases). The release page provides files for both NeoForge and Fabric; select the file matching your loader and review that release's compatibility matrix.

If the Release provides SHA-256 checksums, verify before deployment:

::: code-group

```bash [Linux / macOS]
sha256sum luminara-*.jar
```

```powershell [Windows]
Get-FileHash .\luminara-*.jar -Algorithm SHA256
```

:::

## NeoForge Server

1. Visit the [NeoForge Official Site](https://neoforged.net/), select Minecraft `1.21.1`, and download the `21.1.x` Installer.
2. Run installation in a clean empty directory:

   ```bash
   java -jar neoforge-21.1.x-installer.jar --installServer
   ```

   Replace `21.1.x` with the actual downloaded filename (minimum required is `21.1.117`).
3. Create `eula.txt` and write `eula=true`.
4. Place the FeudalKings-compatible Luminara mod and your NeoForge mods into `mods/`; place Bukkit/Spigot plugins into `plugins/`.
5. Start the server using `run.bat` or `run.sh` generated by NeoForge, and check `luminara.yml` in the root directory after first startup completes.

## Fabric Server

1. Prepare a Fabric Dedicated Server for Minecraft `1.21.1`, using Fabric Loader `0.16.0` or higher.
2. Place Fabric API matching `1.21.1` (minimum `0.115.0`) and the FeudalKings-compatible Luminara mod into `mods/`.
3. Create `eula.txt` and write `eula=true`.
4. Place Bukkit/Spigot plugins into `plugins/`, and launch the server using the Fabric server startup script.

Fabric and NeoForge dependencies are distinct. Do not copy NeoForge-specific dependencies or startup scripts into a Fabric directory; adhere to Release notes and modpack specifications.

## Post-Startup Checks

- Ensure Minecraft, platform, Java, and Luminara versions in logs match the matrix on this page.
- Ensure `/luminara info` executes and reports CraftBukkit package `v1_21_R1`.
- After mods finish loading, enable plugins individually and verify commands, world loading, and save reloading function properly.

When issues arise, reproduce them first in a minimal directory containing only Luminara, the platform API, and essential dependencies before re-adding other mods and plugins. When reporting issues, include the branch, platform (NeoForge or Fabric), full startup logs, and the output of `/luminara info`.
