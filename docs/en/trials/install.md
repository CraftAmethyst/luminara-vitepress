# stable/Trials Installation

This page applies only to Minecraft `1.20.1`, Forge `47.x`, and Java `17`.

## 1. Download Files

Download the Luminara mod matching `stable/Trials` and Minecraft `1.20.1` from [GitHub Releases](https://github.com/CraftAmethyst/Luminara/releases). If the Release provides a `.sha256` checksum file, verify it before deployment:

::: code-group

```bash [Linux / macOS]
sha256sum luminara-*.jar
```

```powershell [Windows]
Get-FileHash .\luminara-*.jar -Algorithm SHA256
```

:::

## 2. Install Forge

Download the installer from the [Forge 1.20.1 Download Page](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html), and execute it in a clean server directory:

```bash
java -jar forge-1.20.1-47.x.x-installer.jar --installServer
```

Replace the filename with the actual downloaded version. Create `eula.txt` and write `eula=true`, then create the `plugins/` directory.

## 3. Place Mods and Plugins

```text
server/
├─ mods/       # Luminara and Forge mods
├─ plugins/    # Bukkit/Spigot plugins
├─ eula.txt
└─ server.properties
```

Start the server using `run.bat` or `run.sh` generated by Forge. Do not run the Luminara mod JAR directly.

## 4. Verification

Confirm that `luminara.yml` is generated in the root directory. Once the server outputs `Done (...)`, run `/luminara info`. When submitting issues, include full logs, mod/plugin lists, and the output of this command.

The default connection address is `lum.rimecraft.top`; ports, firewalls, and proxies still need to be configured according to `server.properties` and your network environment.
