# stable/Trials

## Minecraft 1.20.1 · Forge 47.x · Java 17

This is the Forge branch targeting Minecraft `1.20.1`. Luminara runs as a Forge mod while providing Bukkit/Spigot and partial Paper API compatibility.

### Target Environment

| Item        | Requirement                                                      |
| ----------- | ---------------------------------------------------------------- |
| Minecraft   | `1.20.1`                                                         |
| Forge       | `47.x`, production recommended version per current Release notes |
| Java        | 64-bit Java `17`                                                 |
| CraftBukkit | `v1_20_R1`                                                       |

### Getting Started

1. Download the binary mod labeled `stable/Trials` from [GitHub Releases](https://github.com/CraftAmethyst/Luminara/releases).
2. Install the Forge Dedicated Server according to the [Trials Installation Guide](./install).
3. Place Luminara and other Forge mods into `mods/`, and Bukkit/Spigot plugins into `plugins/`.
4. Check `luminara.yml` after first launch, and execute `/luminara info` to verify the version.

If you need to build from source or contribute to development, please refer to the [Trials Build & Development Guide](./build). For common configurations, compatibility, and FAQs, see [General Documentation](/en/guide/config).
